# 조달청 데이터 허브 — 데이터 다운로드 가이드

작성일: 2026-03-27
대상: 공공입찰 통계 엔진 `bids_history` + `bid_participants` 데이터 수집

---

## 전체 흐름

```
① 검색 조건 설정
② 컬럼 선택
③ 조회 실행
④ 내보내기 설정
⑤ CSV 다운로드
⑥ /admin 페이지에서 업로드
```

---

## ① 검색 조건 설정

### 필수 설정

| 항목 | 설정값 | 주의사항 |
|------|--------|----------|
| **공고게시일자** | 원하는 기간 | 최대 12개월 단위로 나눠서 조회 |
| **낙찰방법** | `적격심사제` **만** 체크 | 다른 방식 선택 시 사정률 분포 오염 |
| **낙찰자선정여부** | `Y` | 개찰 완료·낙찰자 확정 건만 |
| **면허업종제한목록** | `0002` 또는 `0023` | 0002=건축공사업, 0023=조경식재공사업 / 하나씩 따로 조회 |

### 선택 설정 (정확도 향상)

| 항목 | 설정값 | 이유 |
|------|--------|------|
| 수요기관소재시도 | 원하는 지역 | 특정 지역 집중 수집 시 |경기도만
| 소관구분 | 지방자치단체, 교육기관 등 | 발주처 유형 좁히기 |

> **낙찰자선정여부를 Y로 설정해도 개찰순위는 전체가 나올 수 있습니다.**
> 다운로드 후 필터링은 시스템이 자동 처리합니다.

---

## ② 컬럼 선택

아래 항목만 체크합니다. 나머지는 모두 해제.

### 입찰속성
- [x] `입찰공고번호` → `project_id` (공고 식별 키)
- [x] `개찰순위` → `bid_participants.rank` (전체 참여자 순위)
- [x] `면허업종제한목록` → `project_type` 판별 (0002/0023)
- [x] `낙찰하한율` → `lower_limit_rate`
- [x] `투찰율` → `bid_participants.bid_rate` (조달청이 직접 계산해서 제공)

### 여부속성
- [x] `낙찰자선정여부` → 검증용 (Y인 건만 처리)

### 기간속성
- [x] `투찰일자` → `bid_date` (개찰 날짜)

### 공통코드속성
- [x] `낙찰방법` → `bid_type` ("적격심사"로 정규화)

### 기관속성
- [x] `수요기관` → `client_name`
- [x] `수요기관지역` → `region`
- [x] `수요기관사업자등록번호` → `client_id` (발주처 고유 코드, 이름 불일치 해결)

### 분석값속성
- [x] `기초금액` → `base_price`
- [x] `예산가격` → 사정률 계산에 사용 (`adjustment_rate = 예산가격 ÷ 기초금액`)
- [x] `투찰금액` → `bid_participants.bid_amount` / `winner_price`(1순위)
- [x] `입찰참여자수` → `participants`

> **예산가격 = 예정가격**입니다. 복수예비가격 추첨 후 확정된 낙찰 기준 가격으로,
> 이 값을 기초금액으로 나누면 사정률이 됩니다.

## ③ 조회 실행

조건 설정 완료 후 **조회** 버튼 클릭.
결과가 맞는지 건수와 샘플 행을 확인합니다.

---

## ④ 내보내기 설정 ← 핵심

내보내기 버튼 클릭 시 나타나는 옵션창 설정:

| 옵션 | 설정값 | 이유 |
|------|--------|------|
| **파일 형식** | `csv 파일 형태` | 파서가 CSV를 처리. Excel 형식은 사용 불가 |
| **구분자** | `,` (쉼표) | 표준 CSV. 탭은 컬럼 내 텍스트와 충돌 가능 |
| **리포트 제목 내보내기** | **OFF** (해제) | ON이면 파일 상단에 제목 행이 추가되어 첫 행이 헤더가 아니게 됨 |
| **필터 세부사항 내보내시겠습니까** | **OFF** (해제) | ON이면 검색조건 메타데이터 수십 행이 추가됨 |
| **추가 열 제거** | **ON** (선택) | 체크하지 않은 컬럼을 완전히 제외해 파일 크기 감소 |

> ⚠️ **리포트 제목·필터 세부사항을 OFF 하는 것이 가장 중요합니다.**
> 두 옵션이 ON이면 CSV 상단에 수십~백여 행의 메타데이터가 붙어
> 파일을 바로 가져올 수 없습니다.

## ⑥ 시스템에 업로드

서버 실행 후 브라우저에서 `http://localhost:8000/admin` 접속.

1. 포맷: **단순 포맷** 선택
2. **파일 업로드** 탭 → 다운로드한 CSV 파일 선택
3. **가져오기 시작** 클릭

시스템이 자동으로:
- 개찰순위 1순위 행 → `bids_history` (사정률 통계용)
- 전체 순위 행 → `bid_participants` (경쟁 분포 분석용)
- 면허업종 코드 0002 → `실내건축`, 0023 → `조경` 정규화
- 지역명 → 시/도 단위로 정규화 ("경기도 수원시" → "경기")

완료 시 결과 메시지 예:
```
낙찰 데이터 142건 추가 / 참여자 데이터 1,840건 추가
```

## 기간별 반복 수집 방법

조달청 최대 조회 기간이 12개월이므로, 과거 데이터 수집 시 구간을 나눠서 반복합니다.

```
2023-01-01 ~ 2023-12-31  → 다운로드 → 업로드
2024-01-01 ~ 2024-12-31  → 다운로드 → 업로드
2025-01-01 ~ 2025-12-31  → 다운로드 → 업로드
```

공고번호 기준 중복 체크가 자동으로 되므로 같은 파일을 두 번 올려도 안전합니다.

## 문제 해결

| 증상 | 원인 | 해결 |
|------|------|------|
| 업로드 후 "처리할 데이터 없음" | 공종 코드 0002/0023 이외 데이터만 있음 | 면허업종제한목록 필터 재확인 |
| 사정률이 0.95 미만 또는 1.05 초과 | 예산가격 컬럼이 예정가격이 아닌 경우 | 컬럼 선택에서 `예산가격` 사용 확인 |
| 컬럼 누락 오류 | 리포트 제목/필터 세부사항이 ON 상태 | 내보내기 옵션 재설정 후 재다운로드 |
| 낙찰하한율이 80~90 사이 (퍼센트) | 정상 — 파서가 자동으로 0.8~0.9로 변환 | 조치 불필요 |
